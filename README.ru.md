# examie

**[English](README.md) · [Қазақша](README.kk.md) · [Русский](README.ru.md)**

Подготовка к ЕНТ на казахском и русском языках.

Я делаю examie вокруг простого учебного сценария: решить задание, понять ошибку и позже вернуться к теме. Хочется, чтобы практика, объяснения и материалы для повторения были в одном месте.

В этом репозитории показываю проект: здесь есть скриншоты приложения и небольшой пример кода, который можно запустить. Исходный код самого приложения остаётся в закрытом репозитории.

Скриншоты сняты **30 сентября 2026 года** в локальной веб-версии на тестовых данных. Интерфейс — на русском. Это не снимки с телефона и не запись диалога с ИИ. С тех пор интерфейс продолжает меняться. [Подробнее о скриншотах](media/README.md#русский).

## Что я разрабатываю

- **Практика по темам.** Задания по предметам, которые ученик выбрал для подготовки.
- **Работа над ошибками.** Свой ответ рядом с правильным, объяснение и возможность попробовать ещё раз.
- **Алтын.** ИИ-репетитор, с которым можно обсудить тему или задание, в том числе отправленное фотографией. Ответы стоит проверять: Алтын может ошибаться.
- **Повторение.** Конспекты по темам, короткие видеоуроки и вопросы для самопроверки.

Ученическое приложение рассчитано на iOS, Android и веб. В проекте также есть кабинеты для родителей и учителей.

## Небольшой пример кода

[Прогресс просмотра урока](examples/lesson-progress/README.md#русский) — пример подсчёта просмотренной части видео. Повторный просмотр одного фрагмента не увеличивает результат. В примере учтены пересекающиеся интервалы, перемотка и конец видео.

Я написал его отдельно для этого репозитория. Он работает на вымышленных данных и не связан с API приложения или хранением учебного прогресса.

Для запуска нужен Node.js 22 или новее. Из корня репозитория:

```sh
node examples/lesson-progress/demo.mjs
node --test examples/lesson-progress/progress.test.mjs
```

Устанавливать пакеты и вводить ключи не нужно. [Посмотреть код](examples/lesson-progress/progress.mjs).
