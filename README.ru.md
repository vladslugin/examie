## Как устроена подготовка

Ученик выбирает предметы и решает задания по темам. После ошибки можно посмотреть объяснение и попробовать ещё раз. Непонятный шаг можно обсудить с Алтын, ИИ-репетитором, или отправить ему фото задачи.

Для повторения есть конспекты и короткие видеоуроки с вопросами для самопроверки. Приложение разрабатывается для iOS, Android и браузера. Для родителей и учителей предусмотрены отдельные кабинеты.

## Код, который можно запустить

Эти примеры написаны отдельно для публичного репозитория и работают на вымышленных данных. Исходники приложения остаются закрытыми.

### Повторный просмотр

Если посмотреть секунды 0–30, а затем 20–50, получится 50 секунд урока, а не 60. После проверки интервалов, ограничения длительностью видео и сортировки остаётся небольшой расчёт:

```js
let watched = 0;
let coveredUntil = 0;

for (const [start, end] of ranges) {
  watched += Math.max(0, end - Math.max(start, coveredUntil));
  coveredUntil = Math.max(coveredUntil, end);
}
```

Исходный массив не меняется, пропущенные при перемотке участки не засчитываются. Здесь есть [полный пример](examples/lesson-progress/progress.mjs), [тесты](examples/lesson-progress/progress.test.mjs) и [инструкция запуска](examples/lesson-progress/README.md#run).

### Запоздавший ответ

Ученик перешёл к заданию B, пока подсказка к A ещё загружается. Старый ответ не должен заменить новый. Сначала отменяем предыдущую операцию, затем проверяем номер запроса перед обновлением экрана. Проверка нужна и после отмены: операция может проигнорировать сигнал.

```js
const value = await load(controller.signal);

if (requestId !== currentId) return "discarded";

apply(value);
return "applied";
```

При уходе с экрана ожидающий запрос тоже становится неактуальным. Ошибка текущего запроса доходит до вызывающего кода, чтобы экран мог показать её или предложить повторную загрузку. Здесь есть [полный пример](examples/latest-request/latest-request.mjs), [тесты](examples/latest-request/latest-request.test.mjs) и [инструкция запуска](examples/latest-request/README.md#run).

Оба примера запускаются локально на Node.js 22 или новее, без установки пакетов, ключей и обращений к сети.

## Разработка

Приложение ученика написано на React Native, Expo и TypeScript. Веб-кабинеты используют Next.js, серверная часть работает на NestJS и FastAPI с PostgreSQL и Redis.
