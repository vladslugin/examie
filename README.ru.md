## Как устроена подготовка

Ученик выбирает предметы и решает задания по темам. После ошибки можно посмотреть объяснение и попробовать ещё раз. Непонятный шаг можно обсудить с Алтын, ИИ-репетитором, или отправить ему фото задачи.

Для повторения есть конспекты и короткие видеоуроки с вопросами для самопроверки. Приложение разрабатывается для iOS, Android и браузера. Для родителей и учителей предусмотрены отдельные кабинеты.

## Код, который можно запустить

Исходники приложения закрыты. Для этого репозитория я отдельно написал [пример подсчёта просмотренной части урока](examples/lesson-progress/README.md#русский). Он учитывает пересекающиеся интервалы и пропуски при перемотке, а повторный просмотр не увеличивает результат.

Пример работает локально на вымышленных данных. Нужен только Node.js 22 или новее. Здесь можно [посмотреть код](examples/lesson-progress/progress.mjs), [тесты](examples/lesson-progress/progress.test.mjs) и [инструкцию запуска](examples/lesson-progress/README.md#run).

## Разработка

Приложение ученика написано на React Native, Expo и TypeScript. Веб-кабинеты используют Next.js, серверная часть работает на NestJS и FastAPI с PostgreSQL и Redis.
