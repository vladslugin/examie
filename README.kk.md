# examie

**[English](README.md) · [Қазақша](README.kk.md) · [Русский](README.ru.md)**

Қазақ және орыс тілдерінде ҰБТ-ға дайындалуға арналған қолданба.

examie-ді оқушы тапсырманы орындап, қатесін түсініп, кейін сол тақырыпқа қайта орала алатындай етіп жасап жатырмын. Тапсырмалар, түсіндірмелер мен қайталауға арналған материалдар бір жерде болғанын қалаймын.

Бұл репозиторийде жобаны таныстырамын: қолданбаның скриншоттары мен іске қосып көруге болатын шағын код мысалы бар. Қолданбаның бастапқы коды жабық репозиторийде сақталады.

## Не жасап жатырмын

- **Тақырып бойынша жаттығу.** Дайындалып жүрген пәндеріңнен тапсырма орындау.
- **Қателермен жұмыс.** Өз жауабыңды дұрыс жауаппен салыстырып, шешу жолын түсіну және қайта орындап көру.
- **Алтын.** Тақырыпты не тапсырманы талқылауға арналған ЖИ-көмекші. Тапсырманың фотосын да жіберуге болады. Алтын қателесуі мүмкін, сондықтан жауаптарын тексерген жөн.
- **Қайталау.** Тақырыптық конспектілер, қысқа бейнесабақтар және өзіңді тексеруге арналған сұрақтар.

Оқушы қолданбасын iOS, Android және веб үшін әзірлеп жатырмын. Жобада ата-аналар мен мұғалімдерге арналған кабинеттер де бар.

## Шағын код мысалы

[Сабақтың қаралған бөлігін есептеу](examples/lesson-progress/README.md#қазақша) мысалы бейненің қанша бөлігі қаралғанын есептейді. Бір бөлікті қайта қарасаң, ол екі рет саналмайды. Мысалда уақыт аралықтарының қабаттасуы, бейненің басқа тұсына өту және оның аяқталуы ескерілген.

Бұл мысалды осы репозиторий үшін бөлек жаздым. Онда ойдан алынған қарау деректері қолданылады. Ол қолданбаның API-ына немесе оқу нәтижелерін сақтау жүйесіне қосылмайды.

Репозиторийдің түбірлік бумасында Node.js 22 немесе одан жаңа нұсқамен іске қосуға болады:

```sh
node examples/lesson-progress/demo.mjs
node --test examples/lesson-progress/progress.test.mjs
```

Қосымша пакет орнату немесе кіру деректерін енгізу қажет емес. [Мысалдың коды](examples/lesson-progress/progress.mjs).

## Қолданылатын технологиялар

| Бөлік            | Құралдар                                    |
| ---------------- | ------------------------------------------- |
| Оқушы қолданбасы | React Native, Expo, TypeScript              |
| Веб-кабинеттер   | Next.js, React                              |
| Сервер           | NestJS, Python / FastAPI, PostgreSQL, Redis |

Бұл технологиялар жабық репозиторийдегі қолданбада қолданылады. Мұнда тек жобаны таныстыратын материалдар мен дербес мысал бар.
